
# DecodeLabs Data Analytics - Project 1: Data Cleaning & Preparation

## Overview
This project focuses on auditing, scrubbing, and standardizing a raw e-commerce dataset of 1,200 records to ensure high data integrity.

## Key Deliverables
* **Cleaned Dataset:** `Cleaned data set.xlsx` (1,200 unique records, 0% duplicate IDs, 100% ISO 8601 date compliance)
* **Change Log Artifact:** `Project_1_Change_Log.pdf` (Detailed audit trail and transformation log)

## Tools Used
* Microsoft Excel (Data Formatting, Formulas, Power Query)
